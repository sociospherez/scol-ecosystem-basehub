# UK Broadband Opportunity Map (Local Authority Level)

This package contains a self-contained interactive HTML map built from Ofcom datasets.

## Files
- `index.html` — open directly in a browser or host on any static site.
- `README.md` — quick hosting instructions.

## Host it quickly

### GitHub Pages (Public)
1. Create a new repository on GitHub.
2. Upload `index.html` to the repo root.
3. In Settings → Pages, choose **Deploy from branch** → `main` → `/ (root)` → Save.
4. Your map will be live at `https://<username>.github.io/<repo>/index.html`.

### Netlify (Instant Hosting)
1. Visit [https://app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag in `index.html`.
3. Netlify provides a free HTTPS link like `https://broadband-map.netlify.app`.

### Private/Internal Use
- Place `index.html` on any intranet, IIS, Apache, or Nginx static folder.
- Or simply double-click to view locally — works fully offline.
