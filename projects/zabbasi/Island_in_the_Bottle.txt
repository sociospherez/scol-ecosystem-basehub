🌊 Project Overview

Island in the Bottle is a student-facing reflective web experience that uses narrative storytelling to help learners explore their strengths, motivations, and soft skills.
The metaphor centers around being stranded on a mysterious island inside a bottle — guided by the Master in the Bottle — and discovering who you are through a series of choices.

It’s an MVP mock-up:

Self-contained (HTML + CSS + JavaScript).

Runs locally in the browser.

No data storage, backend, or dependencies.



---

🎨 Design Philosophy

Metaphor: Students experience reflection as an adventure — a journey of discovery rather than an assessment.

Goal: Build self-awareness through story, not scoring.

Outcome: Students receive a persona reflection based on their dominant traits.



---

🪞 Scene Overview

1. 🌅 Scene 1 — The Arrival
The student awakens on the island. The Master’s voice greets them.
Purpose: Introduction & reflection.


2. 💬 Scene 2 — The Voice in the Bottle
The first set of reflective choices appear.
Purpose: Assess curiosity & adaptability.


3. 🏝️ Scene 3 — The Fork in the Forest
A symbolic decision between structure and creativity.
Purpose: Observe preference and mindset.


4. 🌊 Scene 4 — The Storm and the Compass
A challenge tests empathy, resilience, and collaboration.


5. 🔮 Scene 5 — The Lighthouse
Reflection scene — envisioning the horizon (future self).


6. 🌟 Scene 6 — The Message to the Self
The player writes a note to their future self — closure.




---

🧭 Traits Tracked

Trait	Description	Persona

Curiosity	Desire to explore, learn, and discover.	Explorer
Empathy	Emotional insight, compassion, connection.	Healer
Creativity	Expression, imagination, perspective.	Storyteller
Resilience	Persistence, groundedness, balance.	Navigator
Collaboration	Teamwork, leadership, harmony.	Builder


Each scene’s choices modify these traits.
At the end, the dominant one defines the persona narrative.


---

🧱 Technical MVP Structure

Single HTML file (no external dependencies).

Inline CSS and JavaScript.

Displays scenes sequentially.

Collects player choices and calculates trait scores.

Ends with a persona reflection and summary.

<script>
const scenes = [
  {
    title: "🌅 Scene 1 — The Arrival",
    text: `You awaken on a soft shore. Around you, sand glitters like glass. A faint glow flickers within a bottle half-buried nearby. 
    As you touch it, a calm voice speaks: "Welcome, traveler. What do you seek on this island?"`,
    choices: [
      { text: "I seek purpose and direction.", traits: { curiosity: 1 } },
      { text: "I want to understand myself better.", traits: { empathy: 1 } },
      { text: "I just followed the tide.", traits: { creativity: 1 } }
    ]
  },
  {
    title: "💬 Scene 2 — The Voice in the Bottle",
    text: `"Curiosity is the compass of the mind," the voice says. "Tell me, when faced with something new..."`,
    choices: [
      { text: "I dive in headfirst, eager to learn.", traits: { curiosity: 2 } },
      { text: "I observe carefully before acting.", traits: { resilience: 1, curiosity: 1 } },
      { text: "I prefer to wait until I’m sure it’s safe.", traits: { empathy: 1 } }
    ]
  },
  {
    title: "🏝️ Scene 3 — The Fork in the Forest",
    text: `You find a path that splits in two. One trail is paved with stones and symbols; the other is wild and painted in color.`,
    choices: [
      { text: "Take the stone path — structured and clear.", traits: { resilience: 2 } },
      { text: "Take the painted path — unpredictable but alive.", traits: { creativity: 2 } }
    ]
  },
  {
    title: "🌊 Scene 4 — The Storm and the Compass",
    text: `A sudden storm erupts! The bottle’s light dims. Someone nearby calls for help — another traveler. What do you do?`,
    choices: [
      { text: "Run to help them first.", traits: { empathy: 2, collaboration: 1 } },
      { text: "Focus on saving the compass and supplies.", traits: { resilience: 2 } },
      { text: "Try to calm everyone and coordinate.", traits: { collaboration: 2 } }
    ]
  },
  {
    title: "🔮 Scene 5 — The Lighthouse",
    text: `After the storm, the Master’s voice returns. "Every choice shapes the light you carry. Look to the horizon — what do you see?"`,
    choices: [
      { text: "A vast sea of possibilities — and I’m ready.", traits: { curiosity: 2, resilience: 1 } },
      { text: "A distant shore — one step at a time.", traits: { empathy: 1, resilience: 1 } },
      { text: "The light reflecting back — myself, changed.", traits: { creativity: 1, empathy: 1 } }
    ]
  },
  {
    title: "🌟 Scene 6 — The Message to the Self",
    text: `Before you leave the island, you write a message in a bottle for your future self. What do you wish to remind yourself of?`,
    input: true
  }
];

let currentScene = 0;
let traits = { curiosity: 0, empathy: 0, creativity: 0, resilience: 0, collaboration: 0 };
let message = "";

function showScene() {
  const sceneContainer = document.getElementById("scene");
  const scene = scenes[currentScene];
  sceneContainer.innerHTML = `
    <h2>${scene.title}</h2>
    <p>${scene.text}</p>
  `;

  if (scene.input) {
    sceneContainer.innerHTML += `
      <textarea id="messageInput" rows="4" style="width:100%;" placeholder="Write your message here..."></textarea>
      <div class="nav-btns">
        <button id="backBtn">Back</button>
        <button id="finishBtn">Finish Journey</button>
      </div>
    `;
    document.getElementById("backBtn").onclick = prevScene;
    document.getElementById("finishBtn").onclick = finishJourney;
    return;
  }

  const choiceHTML = scene.choices.map((c, i) =>
    `<button onclick="chooseOption(${i})">${c.text}</button>`).join("");
  sceneContainer.innerHTML += `<div class="choices">${choiceHTML}</div>`;
  if (currentScene > 0) {
    sceneContainer.innerHTML += `<div class="nav-btns"><button id="backBtn">Back</button></div>`;
    document.getElementById("backBtn").onclick = prevScene;
  }
}

function chooseOption(index) {
  const choice = scenes[currentScene].choices[index];
  for (let t in choice.traits) traits[t] += choice.traits[t];
  nextScene();
}

function nextScene() {
  if (currentScene < scenes.length - 1) {
    currentScene++;
    showScene();
  }
}

function prevScene() {
  if (currentScene > 0) {
    currentScene--;
    showScene();
  }
}

function finishJourney() {
  message = document.getElementById("messageInput").value;
  const dominantTrait = Object.entries(traits).sort((a,b)=>b[1]-a[1])[0][0];
  const personaDescriptions = {
    curiosity: "You are an Explorer — driven by wonder and the thrill of discovery.",
    empathy: "You are a Healer — compassionate, intuitive, and attuned to others.",
    creativity: "You are a Storyteller — imaginative, expressive, and visionary.",
    resilience: "You are a Navigator — steady in storms, grounded in purpose.",
    collaboration: "You are a Builder — bringing people together toward shared dreams."
  };
  
  document.getElementById("scene").innerHTML = `
    <h2>🌅 Journey Complete</h2>
    <p>${personaDescriptions[dominantTrait]}</p>
    <p><strong>Your final message:</strong><br>"${message || 'No message written.'}"</p>
    <p>Your inner light now carries traces of ${Object.keys(traits).map(t => `${t} (${traits[t]})`).join(', ')}.</p>
    <p>Keep this with you — every explorer begins with a question.</p>
  `;
}

showScene();
</script>
</body>
</html>
